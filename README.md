# Elegance Lingerie Store Website

A modern, responsive lingerie store website built with HTML, CSS, and JavaScript. Features a sophisticated design with elegant typography, smooth animations, and mobile-first responsive layout.

## 🌟 Features

### Design & Layout
- **Modern Aesthetic**: Clean, sophisticated design perfect for a lingerie store
- **Responsive Design**: Mobile-first approach that works on all devices
- **Elegant Typography**: Uses Playfair Display (serif) and Inter (sans-serif) fonts
- **Sophisticated Color Scheme**: Pink gradients (#ff6b9d to #c44569) with neutral accents

### Navigation & User Experience
- **Fixed Navigation Bar**: With backdrop blur effect and smooth transitions
- **Mobile Hamburger Menu**: Responsive navigation for mobile devices
- **Smooth Scrolling**: Animated navigation between sections
- **Interactive Elements**: Hover effects and micro-animations

### Sections
1. **Hero Section**: Eye-catching landing area with call-to-action buttons
2. **Collections**: Four main product categories with elegant cards
3. **Featured Products**: Product showcase with pricing and add-to-cart functionality
4. **About Section**: Brand story and company information
5. **Newsletter**: Email subscription form with validation
6. **Footer**: Comprehensive site information and social links

### Interactive Features
- **Shopping Cart**: Add-to-cart functionality with notifications
- **Wishlist**: Heart icon toggle with visual feedback
- **Search Modal**: Product search functionality
- **Newsletter Subscription**: Email collection with success messages
- **Smooth Animations**: Intersection Observer for scroll-triggered animations

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server setup required - runs entirely in the browser

### Installation
1. Download or clone the project files
2. Ensure all files are in the same directory:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Open `index.html` in your web browser

### File Structure
```
new web/
├── index.html          # Main HTML structure
├── styles.css          # CSS styling and responsive design
├── script.js           # JavaScript functionality
└── README.md           # This documentation
```

## 🎨 Customization

### Colors
The main color scheme can be modified in `styles.css`:
```css
/* Primary brand colors */
--primary-pink: #ff6b9d;
--secondary-pink: #c44569;
--text-dark: #2c2c2c;
--text-light: #666;
```

### Typography
Fonts are loaded from Google Fonts:
- **Headings**: Playfair Display (serif)
- **Body Text**: Inter (sans-serif)

### Content
- Update product names, prices, and descriptions in `index.html`
- Modify collection categories and descriptions
- Change company information in the About section
- Update social media links in the footer

### Images
Currently uses Font Awesome icons as placeholders. Replace with actual product images:
```html
<!-- Replace icon placeholders with actual images -->
<div class="product-image">
    <img src="path/to/product-image.jpg" alt="Product Name">
</div>
```
